# one1nfinityloop.github.io

Публичные страницы приложений: политика конфиденциальности и другое, что
магазины требуют открытой ссылкой. Код приложений здесь не лежит.

- `spendless/privacy/` — политика конфиденциальности SpendLess: английский (`index.html`) и русский (`ru/`).
  Источник текста — `docs/privacy_policy.md` в репозитории приложения,
  раздел «Текст для публикации»; меняется там, потом переносится сюда.
